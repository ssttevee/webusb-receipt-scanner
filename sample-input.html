Receipt sample inputs

Capture real raw scanner input through WebUSB, label it, and export the original scanner bytes and manifest. This development app runs on your workstation without Docker.

Use desktop Chrome/Edge with the USB-connected Epson scanner. Capture bypasses application cropping, thresholding, and OCR. Defaults are preserved unless you explicitly select the long-paper profile or another DPI; changes are recorded.

Ready. Use HTTPS or localhost for browser persistence and checksums.

1. Original input

Long paper requires 300 DPI or below. The maximum is a capture bound, not a crop to the paper's width. If the scanner advertises a smaller maximum, scanning will not start. Actual long-paper support still requires a physical bottom check.

Scanner disconnected.

Connect once, start a session, then feed receipts. Each raw scan is saved automatically with unlabelled fields. Stop the session to label samples. Stop waits for the current driver operation to return; partial bytes are retained.
